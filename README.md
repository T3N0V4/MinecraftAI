# MinecraftAI

## Español

MinecraftAI es un mod experimental para Minecraft que hice principalmente por curiosidad, para aprender y porque me divierte probar cosas nuevas.

Una parte importante del proyecto fue desarrollada con ayuda de herramientas de inteligencia artificial. Las usé para programar, probar ideas, corregir errores y acelerar el desarrollo.

No pretende ser un producto terminado ni profesional. Es simplemente un proyecto personal que voy cambiando y mejorando cuando tengo ganas.

Actualmente incluye cosas como:

- Chat con IA dentro de Minecraft
- Contexto del jugador y del mundo
- Tools para consultar información del juego
- Entrada por voz
- Respuestas por voz
- Herramientas de prueba y debug

Si querés probarlo, modificarlo o usar alguna idea del proyecto, sos libre de hacerlo.

Está hecho para Minecraft 1.20.1 con Fabric y Java 17.

---

## English

MinecraftAI is an experimental Minecraft mod I made mostly out of curiosity and fun.

A significant part of the project was developed with the help of AI tools. I used them to write code, test ideas, fix problems, and speed up development.

It is not meant to be a finished or professional product. It is simply a personal project that I change and improve whenever I feel like working on it.

It currently includes things like:

- AI chat inside Minecraft
- Player and world context
- Tools to query game information
- Voice input
- Voice responses
- Debug and testing tools

If you want to try it, modify it, or use ideas from the project, feel free to do so.

Built for Minecraft 1.20.1 with Fabric and Java 17.

---

## Build

Run:

    .\gradlew.bat clean test build
